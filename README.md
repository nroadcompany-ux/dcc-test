## Government support dataset v0.4

- 225 records across 6 major groups and 15 detailed categories
- 73 researched notices and 152 clearly labeled DEMO records
- 15 records per detailed category
- Search, filters, sorting, detail view, and 25/50/100 page size
- Data: `government-support-programs.json`, `government-support-programs.csv`
- QA: `government-support-QA.md`
- Browser data: `support-programs.js`

The Vercel project is connected to this repository and deploys from the main branch.
