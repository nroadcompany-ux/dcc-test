## 1. 목적
생ZONE 예비창업 로드맵과 생존플러스 운영 대시보드를 동일한 시각 언어로 운영하기 위한 기준. V7 실제 화면이 시각적 기준이며 아래 HEX 및 픽셀 값은 스크린샷 분석에 근거한 제안값이다. 실제 CSS와 폰트 원본 확인 전 확정 토큰으로 취급하지 않는다.

## 2. Fact / Observation
- 모바일: 화이트 카드, 연한 블루그레이 캔버스, 둥근 코너, 이미지형 3D 아이콘, 세로 단계/체크리스트, 하단 5개 탭.
- PC: 좁은 좌측 아이콘 탐색, 넓은 본문 영역, 구분선 기반 4개 핵심지표, 블루 막대차트, 간단한 리스트형 도움말.
- 네비게이션 현재 선택 상태는 블루 강조. 비활성/부차 텍스트는 그레이.

## 3. 제안 색상 토큰
- primary-blue: #2164DF
- action-blue: #2874E8
- deep-navy: #233B5E
- secondary-text: #70819C
- surface: #F7F9FC
- soft-blue: #EDF4FF
- border: #DFE6EF
- white: #FFFFFF
검증 전 추정 수치. 블루는 CTA·현재위치·상태 선택 위주로 적용.

## 4. Typography (서체)
- Pretendard 우선 검토. 원본 선언은 추가 확인 필요.
- 모바일 주제목 26–30px, 섹션 18–20px, 카드제목 15–17px, 본문 14–16px, 보조 12–13px.
- PC 페이지제목 22–26px, 섹션 18–20px, 카드제목 15–16px, 본문 14px, 보조 12–13px, 수치 28–32px.
- 숫자 tabular-nums 사용, 텍스트 줄간격 1.45–1.65.

## 5. Spacing / Radius / Shadow (간격·모서리·그림자)
- 기준 간격: 4px, 8px의 배수.
- 모바일 좌우 여백 20–24px, PC 본문 좌우 여백 32–48px.
- 모바일 주요 카드 radius 20–24px; CTA 14–18px; 컨트롤 10–12px.
- 카드 안쪽 16–24px; 섹션 사이 28–40px.
- 얇은 경계선 1px, 낮은 강도의 그림자 사용.

## 6. 모바일 로드맵
- 헤더: 뒤로/화면 제목/로그인
- 인트로: 안내 라벨/13단계 제목/완료 진행률/오픈일 CTA
- 단계 행: 원형 단계번호 + 실물 느낌의 아이콘 + 시점 + 제목 + 설명 + 우향 표시
- 선택 항목: 연한 블루 배경. 단계 흐름: 연결선 유지.
- 하단탭: 홈/로드맵/투데이/혜택/커뮤니티.
- 현재 13단계 구성과 내용은 제품 기준 자료로 별도 관리.

## 7. 모바일 체크리스트
- 제목/완료 갯수/흰색 카드 안에 각 행.
- 행: 24px 안팎의 체크 영역 + 항목명 + 도움말 아이콘.
- 체크/도움말은 별도 동작이며 완료/미완료 시각적 대비 필요.
- '시작 전에 알아두세요', 관련 서비스, 창업학교, 다음 준비 연결.

## 8. PC 장부
- 상단 주/월 선택, 기간 이동, 엑셀, 지출적기.
- 네 개 핵심 지표는 구분선 위주로 한 줄 배열.
- 차트 탭(매출 흐름/날짜별/쓴 돈/계획과 지금), 매출 막대, 목표 점선.
- 하단 요일 평균과 결제 수단 비교.
- 차트는 수치 접근성, 범례, 휴무/미입력 구분, 눌러서 상세 열기를 보장.
- 숫자/단위/집계 범위를 인접한 보조 문구로 설명.

## 9. PC 도움
- 상단 6개 주제 진입: 세무, 노무, 운영자금, 손님 늘리기, 계약·분쟁, 매출이 줄 때.
- 하단 운영학교 목록, 계산기, 내 요청.
- 과도한 카드 테두리 대신 행 구분과 자연스러운 컬럼을 사용.

## 10. 상태별 컴포넌트
- 버튼: 기본/hover/focus/disabled/loading.
- 탭: 선택/비선택.
- 카드: 기본/선택/완료/잠금/오류.
- 체크리스트: 미완료/완료/도움말.
- 데이터: 로딩/빈화면/오류/권한 없음/미집계.
- 상태는 색상만이 아닌 텍스트·아이콘도 함께 제공.

## 11. 접근성 및 QA
- 키보드 포커스 표시, 최소 44px 터치 영역, 대체 텍스트, 의미 있는 라벨.
- 사용자 수치와 샘플 수치 시각적으로 구분.
- 모바일/PC 모두 콘텐츠 잘림, 축 단위, 범례, 상태 보존 확인.
- 디자인 변경은 Figma·Blueprint 및 대표 UI 검수본과 대조.

## 12. 결정 및 다음 Action
Decision: 본 문서는 V7 시각 기준의 운영용 레퍼런스이며 CSS 원본 수치 승인 문서가 아니다.
Proposal: CSS/아이콘 파일/폰트 확인 후 Design Tokens v1.1 확정, Figma 라이브러리 동기화, 대표 승인 후 공식 기준 승격.
